The prepared bundle freezes all source/inputs needed to repeat preparation-era calibration conditions and launch the same development run on a clean checkout with matching dependencies. It contains completed baseline outcomes, not a live population/checkpoint. Do not extract over an existing or active run.

Authoritative live training outputs are under `runs/neat-quality-speed-v1/development/seed-01/`. The default stopping rule is 50 committed generations. All target failures, actual budgets and raw episodes remain saved. Current progress can be read with:

```powershell
& .\.venv\Scripts\python.exe run_neat_quality_study.py status
```

The 50-generation development run is complete: 30,000 candidate training episodes, 300 reference episodes and 7,840 validation episodes for 98 distinct genotypes. None of the 150 saved candidate records passed all gates; all missed the 0.95 m/s required-window speed target. The strongest candidate rejected only for speed is generation 40, rank 0: 60/60 primary plus 20/20 retention, minimum straight speed 0.8842 m/s, worst straight yaw RMS 0.0837 rad/s, and paired-time ratio 1.0103 to fast g134. This is a recorded near miss, not an official winner.

Independent confirmation and fresh final comparison remain pending. A separately versioned follow-up can test the continuous objective; neither the completed result nor its gates may be rewritten. These new files are local until explicitly committed/pushed.
